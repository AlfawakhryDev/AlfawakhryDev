## 👋 About Me

I'm **Abdelrahman Alfawakhry**, a passionate software engineer focused on **C#, C++, and ASP.NET Core**. I care about detail, clean code, and shipping solutions that are **efficient, scalable, and user-friendly**.

I'm also a **mobile developer**. I trained in native mobile development through the **ITI Professional Training Program: *Native Mobile Applications Development with AI Integration***, covering:

- 🍎 **iOS**: Swift, SwiftUI, Objective-C, unit testing, dependency injection, reactive programming
- 🤖 **Android**: Java & Kotlin, Coroutines, Material Design, design patterns, dependency injection
- 🔀 **Cross-platform**: Flutter and Kotlin Multiplatform (KMP)
- 🧠 **AI-assisted development**: Generative AI, prompt engineering, AI coding agents, and workflow automation
